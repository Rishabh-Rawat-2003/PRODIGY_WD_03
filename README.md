# PRODIGY_WD_03 — Tic‑Tac‑Toe Web Application

## 🎯 Task Objective
Create a Tic‑Tac‑Toe game using **HTML, CSS, and JavaScript** with:
- Click handling & turn switching (X / O)
- Win / draw detection
- **New Game** and **Reset Scores**
- Modes: **Player vs Player** and **Player vs Computer (minimax)**

No backend is required.

## 🧱 Tech Stack
- HTML
- CSS (responsive grid, animations)
- JavaScript (DOM, game state, minimax)

## 🚀 Run Locally
1. Download or clone the repo.
2. Open `index.html` in your browser.

```bash
# Optional local server
python -m http.server 8000
# open http://localhost:8000
```

## 🧠 How the AI Works
The computer plays as **O** using the **minimax algorithm**, which explores all possible moves to choose the one that maximizes its chance of winning (and minimizes loss). For Tic‑Tac‑Toe, this guarantees optimal play.

## 📚 Learnings
- Event‑driven programming & state management
- Detecting win conditions efficiently
- Implementing a classic minimax search
